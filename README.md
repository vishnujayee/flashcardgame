# Flashcard Frenzy

A multiplayer flashcard game built with Next.js App Router, Supabase Auth, and MongoDB.

## Environment

Copy `.env.example` to `.env.local` and fill in values.

```bash
cp .env.example .env.local
```

Set a strong `APP_SECRET` for signing guest sessions (32+ random chars).

## Development

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```
